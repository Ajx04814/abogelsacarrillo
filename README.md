## Antes de publicar
1. Configurar el número oficial de WhatsApp en los enlaces `wa.me`.
2. Agregar correo, dirección y perfiles sociales oficiales.
3. Confirmar los datos de trayectoria y marcas acompañadas.
4. Incorporar fotografías autorizadas de Elsa en `assets/`.
5. Revisar el contenido jurídico con Elsa.
6. Configurar dominio, hosting, formulario, privacidad, analytics y Search Console.

## Desarrollo
Abrir `index.html` localmente o habilitar GitHub Pages en Settings → Pages → Deploy from branch → main → /(root).

Las imágenes deben estar en `assets/` con los nombres indicados no HTML.
