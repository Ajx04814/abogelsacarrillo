# Archivo de imágenes de Elsa Carrillo

Se preparó un paquete comprimido con **35 imágenes** creadas para la identidad y comunicación profesional de Elsa Carrillo: retratos, poses de abogada, escenas de oficina, documentos, piezas editoriales y composiciones de Instagram.

## Paquete de imágenes
El archivo ZIP está disponible en el espacio de trabajo de esta conversación como `elsa-imagens-github.zip`. Para incorporarlo al repositorio, subirlo a esta ruta:
`assets/elsa-imagens.zip`
